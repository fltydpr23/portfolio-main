01 Phase 1: Physical & Structural Triage
Four Corner Chassis & Dent Audit
Inspect all 4 chassis corners. Carefully inspect the existing dent—confirm strictly cosmetic.
Chassis Torsion & Seam Alignment
Confirm lid sits 100% flush when closed. Check bottom case gaps and chassis for bends/twists.
Bottom Plate & Screw Inspection
Inspect Pentalobe screws for stripping, wear, or unauthorized tool marks.
Display Frame & Hinge Action
Open/close display ~10 times. Check hinge resistance and verify screen glass has no hairline cracks or pressure spots.
I/O Port Physical Integrity
Flash phone light into MagSafe, 3x Thunderbolt, HDMI, Headphone, and SD card slot. Check for corrosion or bent pins.
Interrogate Seller On Repairs
Ask explicitly: Has it ever been opened? Logic board, display, or battery replaced? Any liquid exposure?
02 Phase 2: Hardware Specs & Enterprise Locks
About This Mac Verification
Confirm: 16-inch MacBook Pro, Apple M1 Max, 64GB Memory, 1TB SSD.
Hardware Serial Triangulation
Confirm terminal output matches 'About This Mac', the bottom case engraving, and original box.
system_profiler SPHardwareDataType
MDM & DEP Corporate Lock Audit
Run both enrollment status terminal commands. MUST show Enrolled via DEP: No.
profiles status -type enrollment
sudo profiles show -type enrollment
If Enrolled via DEP = YES or MDM Enrollment = YES: STOP. DO NOT BUY.
System Settings Profile Check
Navigate to System Settings → General → Device Management. Ensure zero corporate profiles are loaded.
Battery Health & RAW Capacity Verification
Check condition is "Normal". Compare vs seller claims (~106 cycles / ~94% capacity). Run raw dump:
ioreg -l | grep -i capacity
Apple Warranty & Coverage Verification
Check serial on checkcoverage.apple.com to verify AppleCare+ active status.
03 Phase 3: Display, I/O & Peripheral Stress
Display Color Pixel & Backlight Test
Launch full-screen pixel generator (White, Black, Red, Green, Blue, Grey). Check dead/stuck pixels, pressure spots, backlight bleed.
ProMotion 120Hz Refresh Rate Check
System Settings → Displays. Confirm ProMotion active. Drag window rapidly across screen—verify glass-smooth rendering.
Test ALL USB-C / Thunderbolt Ports (3 Total)
Plug external SSD into every port individually. Verify stable detection, mount speed, and read/write access.
MagSafe Charging Port
Plug MagSafe charger. Verify orange/green LED, charging sound, and percentage increase.
HDMI Output & SD Card Reader
Insert SD card (verify read/write). Connect HDMI out to display (verify video & audio routing).
3.5mm Headphone Jack
Plug in wired headphones. Check Left/Right channels and turn plug inside jack to check for static/crackling.
Keyboard & Touch ID Sweep
Open TextEdit. Click EVERY key (Letters, Numbers, Shift, Cmd, Option, Ctrl, Fn, Esc, Arrows, Space, Return, Delete, Brightness, Volume). Set up Touch ID.
Force Touch Trackpad Inspection
Click top corners, middle, bottom. Perform 2-finger scroll, pinch-to-zoom, 3-finger gesture, Force Click. Check dead zones.
Camera, Mics & Speaker Sweep
Launch Photo Booth (Check camera clarity). Record voice memo (check microphone clarity). Play high-volume audio (check bass & stereo rattling).
Wi-Fi & Bluetooth Stability
Connect to phone hotspot, execute speed test. Pair Bluetooth headphones, walk 5 paces away—check disconnects.
04 Phase 4: Diagnostics, Thermals & Dev Workloads
Apple Diagnostics (Hardware Test)
Shutdown → Hold Power button until Options appear → Press Cmd + D. Confirm 0 hardware errors.
NVMe Storage Performance Audit
Run Blackmagic Disk Speed Test. Target: Multi-GB/s reads & writes with zero drops or errors. Run storage profile:
system_profiler SPStorageDataType
CPU/GPU Thermal Stress (Geekbench / Cinebench)
Run multi-core Cinebench 2024 / Geekbench 6. Watch for shutdowns, screen artifacts, thermal throttling or fan grinding.
Real-World Gaming Stress (15 Mins)
Launch a native Steam game for 15 mins. Check rendering stability, heat distribution, fan noise, zero graphical glitches.
Local Dev Workflow & AI Inference Stress Test
Launch Cursor/VS Code, Next.js build, Docker containers, and run local LLM (Ollama / MLX). Check memory swap and system responsiveness.
